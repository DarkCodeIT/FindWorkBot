# 🤖 FindWorkBot — Async Telegram Job Scraper & Bot

> **Статус проекта:** Архитектурный проект для портфолио (демонстрация навыков backend-разработки, парсинга и работы с асинхронным Python).

## 📌 О проекте
**FindWorkBot** — это комплексное автоматизированное приложение на Python. Проект решает задачу регулярного мониторинга вакансий с сайтов-источников, их безопасной обработки, сохранения в удаленную базу данных и мгновенной выдачи пользователям через интерактивный интерфейс Telegram-бота.

---

## 🛠 Технологии и стек
* **Язык:** Python 3.10+
* **Telegram API:** `aiogram` (асинхронный фреймворк)
* **Парсинг:** `BeautifulSoup`, `asyncio`, `requests`
* **База данных:** MongoDB (NoSQL) + Motor (асинхронный драйвер)
* **Архитектура:** Async/Await, FSM (Finite State Machine), Middlewares, Modular Monolith

---

## 📂 Архитектура приложения
Проект написан с соблюдением принципов чистой архитектуры и разделения ответственности:
```text
FindWorkBot/
│
├── bot/                    # Интерфейс Telegram-бота
│   ├── handlers/           # Обработчики команд, текстовых сообщений и админ-панели
│   ├── keyboards/          # Инлайн и Reply клавиатуры
│   ├── middlewares/        # Защита от флуда (Anti-flood)
│   └── utils/              # Состояния (FSM) и утилиты форматирования
│
├── database/               # Слой работы с данными (MongoDB сервисы, статистика)
├── parsing/                # Фоновый парсер сайтов и планировщик задач (таймер)
├── logs/                   # Модульная система логирования
├── const.py                # Текстовые константы
├── requirements.txt        # Зависимости проекта
└── run.py                  # Единая точка входа (Entry point)
